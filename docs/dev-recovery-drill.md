# dev 环境恢复演练

## 目标

验证开发部署的 PostgreSQL 备份可以恢复，并确认恢复后的结构与关键数据可读；同时验证真实 Dex OIDC discovery 和应用登录发起边界。演练不覆盖生产异地备份，也不把测试账号、Cookie、数据库连接串或其他凭据写入仓库。

## 2026-08-01 演练记录

- 环境：通过 SSH 隧道访问、只绑定远端回环地址的 `dev` 环境。
- 备份：UTC 2026-08-01 生成的 PostgreSQL custom-format 每日备份，大小 23,219 字节。
- 恢复：创建隔离的临时数据库，以 `pg_restore --exit-on-error --no-owner --no-privileges` 完整恢复，验证后立即删除临时数据库。
- 结构验证：恢复出 10 个 `public` 表，`schema_migrations` 包含 4 条迁移记录。
- 数据验证：恢复库中的 `users` 表包含预期的 1 条开发账号记录；未输出账号内容或其他个人数据。
- OIDC 验证：Dex discovery 返回与配置完全一致的 issuer，授权、token 和 JWKS 端点均保持同一回环来源；`/api/auth/login` 返回 `302`、OIDC 事务 Cookie，并跳转至 Dex 授权端点。
- 服务验证：`/api/health` 返回 `200`，实时模型与同步存储均启用；Web、API、Dex 和 PostgreSQL 服务均在运行。
- 结果：备份可用于同版本数据库恢复，OIDC 登录发起链路可用。真实浏览器完成授权回调、创建服务端会话并执行跨设备同步仍需单独验收。

## 2026-08-02 浏览器验收尝试

- 通过文档化 SSH 隧道确认 Web 健康检查与 Dex discovery 均返回 `200`，issuer 保持预期回环来源。
- 使用真实浏览器从应用点击“登录并同步”，成功经过 `/api/auth/login` 跳转到 Dex 本地登录页；登录页展示邮箱、密码和提交控件。
- 当前阻塞：服务器配置只保存测试账号的密码哈希，本次运行无法安全取得明文测试密码；未猜测、重置或输出任何凭据。
- 待续验收：由持有测试密码的操作者完成登录后，继续确认回调、服务端会话轮换、一次上传和第二浏览器的云端恢复。

## 2026-08-03 浏览器验收尝试

- 远端 Web 与 API 用户服务均为 `active`，`/api/health` 返回 `200`，实时模型与同步存储保持启用。
- 重新建立文档化 SSH 回环隧道后，宿主机可访问远端服务；当前自动化可用的应用内浏览器隔离宿主机回环网络，无法访问 `127.0.0.1:8088`。
- 当前没有连接可访问宿主机回环网络的桌面浏览器，因此未进入 OIDC 登录页；此前测试账号明文密码不可用的阻塞仍未改变。
- 未猜测、重置、读取或输出任何凭据。后续需在已连接的桌面浏览器中由持有测试密码的操作者完成回调、会话轮换、一次上传和第二浏览器云端恢复。

## 2026-08-03 浏览器验收续试

- 重新建立文档化 SSH 回环隧道后，应用内浏览器已能打开远端 Web，并从“登录并同步”经过应用登录端点进入真实 Dex 邮箱与密码表单。
- `/api/health` 同时返回 `200`，实时模型、同步和 PostgreSQL 就绪检查均启用。
- 服务器仍只保存测试账号密码哈希，仓库和本地运行配置没有明文测试密码；未猜测、重置或输出凭据。
- 真实授权回调、服务端会话和跨浏览器恢复继续由同一最小阻塞项限制：持有测试密码的操作者需在该浏览器完成一次登录。

## 下次演练

1. 受版本控制的 `ai-learning-os-restore-drill.timer` 每周自动执行 `~/services/ai-learning-os/restore-drill.sh`，从私有备份目录选择最新受管归档；也可传入绝对备份路径手动演练。命令会先确认验证运行器由当前用户独占且不可被其他用户写入，再只读验证绝对路径、文件归属、私有权限、sidecar 文件名、SHA-256 和 PostgreSQL custom archive 可读性。
2. 命令只会使用唯一命名的隔离数据库，完整恢复后验证核心表、迁移数量和非敏感行数，并在成功、失败或中断后删除临时库；禁止手工改为运行中的应用数据库。
3. 记录备份生成时间、文件大小、预检结果和演练输出的数量，不记录标识符、文件内容或学习正文；再运行只读同步仓库检查。
4. 通过真实浏览器完成 OIDC 回调，验证会话轮换、一次上传和一次云端恢复。
5. 删除临时恢复库并确认运行中服务的健康状态未受影响。
