# AI Learning OS 数据与隐私说明

## 当前数据边界

AI Learning OS 默认在当前浏览器保存学习计划、每日任务、教学回答、成果、评估、难度反馈和复盘。登录并启用同步后，同一内容会保存到部署者配置的 PostgreSQL 数据库，以便跨设备恢复。

创建计划、教学会话或成果评估时，当前步骤所需的学习目标和用户输入会发送到本机 API。只有部署者显式配置实时模型后，API 才会把该请求发送给所选模型提供商。应用不保存模型密钥、OIDC 令牌、浏览器指纹或原始模型请求日志；数据库只保存应用会话令牌的 SHA-256 哈希。

## 用户控制

- “导出学习记录”下载带版本和导出时间的 JSON 副本。副本包含学习正文，应由用户自行安全保管。
- “导入学习记录”会先完整验证并预览目标、学习日和导出时间。完整组合可只合并新目标并保留本地同 ID 版本、当前选择和预算；全部替换仍需明确确认。
- “删除本地数据”只清除当前浏览器，不影响已同步的云端副本。
- “管理设备”只显示仍有有效登录会话的设备；退出指定设备会撤销它的全部会话，但保留本地和云端学习记录。
- “退出所有设备”会立即撤销账号的全部设备和登录会话，但保留云端及当前浏览器中的学习记录；重新登录后可继续同步。
- 已登录用户的“删除账号”会再次确认，然后事务化删除应用账号、OIDC 身份映射、所有设备和会话、云端计划及每日记录，同时清除当前浏览器进度。该操作不可撤销。

当前开源原型不配置生产备份，也不持久化安全审计输出；部署者如果收集标准输出或创建数据库备份，必须在上线前公布保留期限、访问范围和删除传播时限。模型提供商对请求的处理受部署者所选服务及其条款约束。

## MVP 保留期限

- 主数据库中的账号和学习数据保留至用户主动删除账号；删除请求会立即清除在线主库记录。
- PostgreSQL 每日备份保留 7 天，账号删除最迟在 7 天后从滚动备份中自然淘汰。恢复备份后必须重新执行恢复点之后的删除请求。
- 应用安全与基础设施日志保留 14 天；开发环境未接入集中日志，只启用单容器最多 3 个、每个 10 MB 的滚动日志。
- 应用不保存模型请求正文或模型响应日志，并对 OpenAI Responses 请求设置 `store: false`。模型提供商应优先选择零数据保留；若兼容服务不提供该选项，MVP 接受的提供商侧最长保留期限为 30 天，并须在隐私说明中注明服务商。
- 本地导出文件由用户控制，不受服务端自动删除和上述期限影响。

## 恢复演练

每次更改学习状态格式、导入逻辑或同步存储后执行以下演练：

1. 创建并完成至少一个含教学回答和成果评估的学习日。
2. 导出 JSON，记录主题、当前学习日和完成任务数。
3. 删除当前浏览器数据，确认旧版和当前版存储键均被清除。
4. 导入刚导出的 JSON，确认替换预览正确，再完成恢复。
5. 核对主题、当前学习日、任务状态、教学回答、成果和评估均保持一致。
6. 登录测试账号，完成同步，在空浏览器中恢复云端副本。
7. 删除测试账号，确认会话失效且所有用户所属数据库行已级联清除。

本地导出、完整校验、确认替换和旧存储键清理由组件测试覆盖；账号级联清除由 PostgreSQL 契约测试覆盖。需要真实 OIDC 提供商和部署数据库的第 6–7 步属于上线环境演练，不能由无凭据的本地 CI 代替。

## 部署前责任

- 按上述 MVP 基线实施数据库备份、基础设施日志和模型提供商保留期限，并在更换服务商时重新核对。
- 加密传输和备份，限制运维访问，并记录删除请求在所有备份中的到期时间。
- 在每次发布前执行上述恢复演练，并记录时间、环境、结果和负责人。
- 多实例部署默认使用 PostgreSQL 共享固定窗口限流器；部署迁移后，各实例会原子共享哈希客户端键计数，不保存原始 IP。也可在可信网关实施更严格的外层限流。
- 采集 `/api/health` 的 60 秒滚动 `capacity` 指标，至少监控同步读写请求数、进行中请求、拒绝/失败、限流命中和延迟；多实例部署应由监控系统聚合所有实例。
