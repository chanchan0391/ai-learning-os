# AI Learning OS MVP 产品说明

## 目标

验证一个核心假设：把模糊学习目标立即转化为可完成的路线和当天行动，能否降低开始学习的阻力，并帮助用户形成完整的“学习—实践—反馈—复盘”闭环。

## 首个垂直切片

### 用户输入

- 学习主题
- 当前能力
- 目标结果
- 每日可投入时间
- 学习周期

### 系统输出

- 覆盖整个周期的四阶段路线
- 第一天的诊断、学习、实践和复盘任务
- 每项任务的时间预算
- 可持续保存的完成状态

### 成功标准

1. 用户可以在两分钟内建立第一个计划。
2. 当天任务总时长严格等于用户可投入时间。
3. 每天同时包含输入、输出和反思，而不只是阅读材料。
4. 用户刷新页面后不会丢失计划和完成进度。

## 产品决策

### 先使用确定性规划器

首版不依赖 LLM API。确定性规则可以提供稳定的测试基线，并让团队先验证交互闭环。未来的 Planner Agent 应实现相同的 `LearningPlan` 输出契约。

### 首个目标用户

默认示例采用“有 Java 背景、希望成为 AI Agent 工程师”的技术人员，与项目冷启动策略一致。规划器也支持其他学习主题的通用路线。

### 数据边界

当前所有数据保存在浏览器本地，不上传服务器。账号、多设备同步和云端数据模型进入后续阶段。

## 暂不包含

- LLM 对话和动态教学
- 用户账号与云同步
- 多天日历与连续学习记录
- Evaluator Agent 自动评分
- Review Agent 间隔复习
- 课程市场、社区和企业管理后台

## 后续验证指标

- 目标创建完成率
- 第一天任务开始率和完成率
- 连续 7 天学习率
- 用户对任务难度和相关性的评分
- 计划被人工修改的比例
