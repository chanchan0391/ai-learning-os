# AI Learning OS MVP 产品说明

## 目标

验证一个核心假设：把模糊学习目标立即转化为可完成的路线和当天行动，能否降低开始学习的阻力，并帮助用户形成完整的“学习—实践—反馈—复盘”闭环。

## 首个垂直切片

### 用户输入

- 学习主题
- 当前能力
- 目标结果
- 每日可投入时间
- 学习周期

### 系统输出

- 覆盖整个周期的四阶段路线
- 每天的诊断、学习、实践和复盘任务
- 每项任务的时间预算
- 可持续保存的完成状态

### 成功标准

1. 用户可以在两分钟内建立第一个计划。
2. 当天任务总时长严格等于用户可投入时间。
3. 每天同时包含输入、输出和反思，而不只是阅读材料。
4. 用户刷新页面后不会丢失计划、每日反馈和历史进度。
5. 用户完成当天闭环后，可以基于难度反馈进入下一天。

## 产品决策

### 确定性规划器作为开发基线

没有模型凭据时使用确定性规则，提供稳定的测试基线并支持完整产品开发。配置模型后，Planner Agent 通过服务端 `ModelProvider` 生成相同的 `LearningPlan` 输出，界面和领域模型不需要改变。

### 首个目标用户

默认示例采用“有 Java 背景、希望成为 AI Agent 工程师”的技术人员，与项目冷启动策略一致。规划器也支持其他学习主题的通用路线。

### 数据边界

学习计划、每日任务、教学回答、成果提交、评估结果、难度反馈和历史进度首先保存在浏览器本地。当前持久化格式为版本 3；版本 1 计划和版本 2 学习记录会自动迁移，无法验证的数据会安全重置。用户可以下载单目标 JSON，也可以一次备份全部进行中目标、归档目标和本地跨目标时间预算。单目标恢复只替换同一目标；完整组合恢复会先校验目标唯一性、归档完整性、当前选择和预算。学习者可以只合并本地不存在的目标，跳过同 ID 版本并保留本地当前选择、进度和预算；也可以经明确确认替换当前浏览器的全部学习数据。用户还可以通过二次确认永久删除当前浏览器中的全部学习数据。登录并配置同步服务后，本地更改会进入持久自动队列：快速编辑被合并，离线更改在恢复连接后重试，冲突必须明确选择版本。创建目标、教学会话或成果评估时，浏览器会把当前步骤所需内容发送到本机 API；启用实时模型后，本机 API 会把这些内容发送到配置的模型厂商。界面已提供简短提示，正式上线前仍必须增加完整的隐私告知和数据保留策略。

浏览器可同时保存多个进行中的版本 3 目标。用户能从当前看板新建并行目标、在目标间切换；原单目标键会在首次读取时自动迁移，切换和新建不会丢失其他目标。跨目标每日清单从各目标尚未完成的任务实时派生，先按恢复、复习、稳定风险排序，再按任务位置在目标间轮转；设置总预算后只纳入可完整容纳的原子任务，不拆分或改写原计划。完成全部计划学习日后，可把完整快照移入独立归档；若仍有进行中目标，界面自动切换到下一个。归档保留每日记录、成果、评估、阶段笔记和阶段回顾，且可恢复为进行中目标查看；也可直接导出以目标命名的版本化 JSON 备份和目标证据 Markdown，不改变归档或当前目标选择。登录状态下，归档计划带 `archivedAt` 标记上传；其他设备会下载并完整校验缺少的归档，而活跃计划恢复仍忽略归档标记。云端客户端会协调所有本地活跃目标并下载其他设备新增的目标；revision 与内容指纹按计划隔离，后台同步其他目标时不改变当前选择。

跨目标首页允许学习者设置 15–1440 分钟的每日总时间预算。超载判断使用各目标当天全部任务的计划分钟数，而不是随勾选减少的剩余分钟数，避免完成部分任务后掩盖当天原始投入。预算是当前浏览器的节奏偏好，不进入学习计划或云端同步；学习者可随时清除，删除本地学习数据时也会一并删除。超载时界面只提示差额，并建议优先保留需关注目标和最小学习闭环，不自动删除或改写任务。

跨目标周回顾按自然日比较最近 7 天与此前 7 天，不保存第二份分析状态。每个目标展示实际完成任务的计划分钟占比、完成日、平均成果评分及其变化，并以“偏难日”变化作为可解释的风险趋势；当前中断、到期复习和最近难度仍作为优先级补充信号。系统只推荐一个本周优先目标，不自动重分配时间或改写任何计划。缺少前一周期证据时明确标记为基线，避免把无数据解释成改善或恶化。学习者可将同一派生快照导出为 Markdown，保留周期、组合汇总、逐目标证据和本周优先项，用于长期组合复盘。

## 暂不包含

- 托管式账号注册和生产级云同步服务
- 更丰富的 Review Agent 题型与跨阶段知识关联（当前已能自动判分主动回忆答案，并按“忘记、费力、轻松”动态调整 1、3、7、14 天间隔）
- 课程市场、社区和企业管理后台

Teacher 与 Evaluator 已接入当前学习任务：学习任务要求完成主动理解检查，实践任务要求提交成果并展示四维反馈。当前是单轮、结构化教学流程，不是开放式多轮对话。

Review Agent 不增加独立复习队列，而是从已保存的 Evaluator 结果和历次回忆表现派生安排。`needs-support`、`developing` 或仍含误解的结果会在次日进入诊断任务，要求用户先闭卷主动纠错和复述最小下一步。Review Agent 只根据答案中可见的证据给出 0–4 分、证据摘要和一个最小改进动作，并把分数映射为“忘记、费力、轻松”；系统据此把间隔调整为 1、3、7 天，连续轻松回忆最长延长到 14 天。完整答案与判分证据会保存在版本 3 学习记录中。

### 学习周回顾

周回顾不保存第二份分析状态，而是从最近 7 个已完成学习日实时派生。界面汇总完成日、投入分钟、平均成果评分、偏难日和轻松回忆次数，并优先选择窗口内最低分评估的 `nextAction` 作为唯一的最小下一步。没有评估证据时，回顾会引导学习者先完成可验证成果；连续偏难时则优先提示缩小任务范围。

### 学习日历

完整日历同样不保存第二份视图状态，而是按自然日期聚合版本 3 学习记录。界面支持在有记录的月份间导航，并按日期展示进行中或已完成状态、投入时间、平均成果评分、难度反馈和反思；同一自然日完成多个学习日时会保留每一条记录。

### 纵向学习趋势

周回顾会把最近完成日与紧邻的前一组等长完成日比较，窗口随证据量从 2 天增长到最多 7 天。系统比较成果评分、偏难日和轻松回忆变化，并把方向归纳为“改善、稳定、需要关注”；不足 4 个完成日或两边缺少成果评估时明确显示证据不足。趋势完全从版本 3 学习记录实时派生，不增加同步字段，也不把自然日缺口错误解释为表现下降。

### 跨阶段重复误解

系统会按学习日所属阶段扫描 Evaluator 记录的误解。只有同一误解在至少两个不同阶段出现时才建立关联；匹配仅归一大小写、空白和标点，不用模糊语义相似度合并不同判断。页面展示原始误解、来源阶段和学习日，并生成要求比较各阶段案例、纠正判断和给出可验证例子的主动回忆提示。学习者可把提示加入当天任务；同一提示当天只加入一次，提交闭卷答案后由 Review Agent 按现有 0–4 分量表自动判分，并把全部关联来源日写入 `reviewPerformance`，由后续间隔计划继续调度。关联本身仍从版本 3 记录实时派生，只有学习者明确加入的每日任务和判分证据参与持久化、导出与同步。

### 阶段结束回顾

只有完成阶段最后一个计划学习日后才能生成阶段结束回顾。系统从该阶段的全部完成日中选取评分最高的成果作为代表证据，汇总量表中达到 3 分以上的可迁移能力，并把最低分成果的 `nextAction` 带入下一阶段应用；缺少评估时使用阶段复盘和明确的补证据提示。学习者可逐项编辑阶段目标回顾、代表成果、可迁移能力和下一阶段应用。回顾作为 `LearningPlan.retrospectives` 的可选字段参与本地备份、进展 Markdown 导出与跨设备同步，旧版计划仍按空集合兼容读取。

### 阶段掌握度检查

阶段完成后，系统从该阶段已经保存的 Evaluator 结果实时汇总理解、应用、证据和反思四个维度，不保存第二份评分。没有评估成果时明确标记“证据不足”；有评估但任一维度平均低于 3 分或成果总分平均低于 12/16 时标记“需要加强”；四维平均均至少 3 分且成果总分平均至少 12/16 时才标记“可以进入下一阶段”。首次最小下一步复用阶段内最低分成果的 `nextAction`，缺少成果时要求补充一份可验证实践并获取四维评估；完成补强后则沿用最新补强评估的 `nextAction`。未达标时，学习者可把这项行动加入当前学习日，形成一条去重的实践任务，并沿用现有成果提交和四维 Evaluator 流程；新增任务会从当天原任务中重新分配分钟，保持每日总预算不变。若最终阶段在最后一个计划日完成后仍未达标，学习者可以开启一个计划外补强学习日；该日仍保留完整每日预算和学习闭环，并在完成前暂时隐藏归档入口。补强任务保存来源阶段、学习日、原任务和原始最小行动；评估完成后，阶段检查纳入这份证据，并展示总分与四维均分的补强前后变化。补强成果只归入其显式来源阶段，不因实际发生在后续阶段的日历范围内而污染另一阶段，也不会在来源阶段内重复计数。目标级掌握度再汇总所有已完成阶段，明确区分“计划日程完成”和“全部阶段证据达标”；优先顺序先选择完全缺少评估证据的阶段，再选择平均成果分最低的待加强阶段，并复用该阶段的唯一最小下一步。目标结论、阶段达标数量和优先项同时显示在界面与学习进展 Markdown 中，不阻断学习者继续学习或归档；学习者也可直接从目标优先项把同一补强实践加入当前学习日，或在计划完成后开启对应阶段的计划外补强日。该入口复用阶段补强任务、来源和去重规则，不保存第二套目标级行动状态。计划完成后可另外导出独立的目标证据报告，报告复用相同派生结论，按阶段列出四维平均、证据份数、补强变化和可编辑阶段回顾，并附每份成果正文、Evaluator 逐维证据与反馈、误解和最小下一步，便于审计、长期留存或向他人说明学习成果。

## 后续验证指标

- 目标创建完成率
- 第一天任务开始率和完成率
- 连续 7 天学习率
- 用户对任务难度和相关性的评分
- 计划被人工修改的比例
- 周回顾最小下一步的后续完成率
